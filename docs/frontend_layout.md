# Frontend placeholder

Phase 1 exposes only a static project introduction. The event timeline and other
product pages remain in Phase 9, after real data flows.

The initial layout uses one readable column with a serif title and sans-serif
body. Later, the forward event timeline will become the primary visual element.

Named colors: paper `#F7F4EC`, ink `#202A34`, muted `#53616C`, rule `#CDD3D5`,
accent `#285D76`. Typography uses system Georgia for the title and system Arial
for body text, avoiding a network font dependency. Sizes: title 3rem, body 1rem,
intro 1.25rem, small text 0.875rem. Layout starts at 1.5rem padding on mobile and
caps the content at 48rem. No animation is necessary for this placeholder.
